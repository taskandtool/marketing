# research/

What was learned, one file per subject, each line citing the `raw/` file
it came from (the `research` skill):

```
research/competitors/<name>.md   what they run, for how long, the hooks and angles they repeat
research/hooks.md                hooks seen in the wild, with links into raw/
research/audience.md             what customers want, dislike and worry about, in their words
research/brief.md                the current summary: ranked hypotheses to test
```

Patterns, never copies: what is recorded is the idea one level above the
execution, so nothing a competitor made is reused.
